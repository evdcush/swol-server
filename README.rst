

Servers:

- chat: ``docker-compose.yml``
- embed: ``embed/docker-compose.yml``
- ASR: ``whisper/docker-compose.yml``

All proxied through an openai API via LiteLLM (``litellm/docker-compose.yml``).


``llma``
========

this is a convenient interface to the models.

useful for thos elike me who constantly tweak things or experiment on models.

source this bad boy to your ``~/.local/bin``.
